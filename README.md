# AAYWA Website Starter

A modern AAYWA-only website starter built with:

- Next.js
- TypeScript
- Tailwind CSS
- Lucide icons

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Current homepage sections

- Hero
- About AAYWA
- Vision & Mission
- Our Work
- Impact
